## 🛠️ มีอะไรใหม่ใน Air Gesture v6.0.1 (Hotfix Update)

### 🤖 แก้ไขปัญหา Gemini AI API เชื่อมต่อไม่สำเร็จ (HTTP 404 Not Found)
- **ปรับเปลี่ยน Model Endpoint เริ่มต้นเป็นทางการ**: เปลี่ยนจากชื่อรุ่นที่ไม่มีใน API สู่รุ่นทางการที่มีให้บริการฟรีบน Google AI Studio: `gemini-2.0-flash`
- **ระบบค้นหารุ่นอัตโนมัติ (Dynamic Model Discovery)**: เพิ่มการเรียก `GET /v1beta/models` เพื่อตรวจสอบสิทธิ์ของ API Key และดึงรายชื่อโมเดลที่บัญชีของผู้ใช้รองรับแบบเรียลไทม์ โดยไม่เสียโควตาโทเคน
- **ระบบสำรองโมเดลอัจฉริยะ (Multi-Model Fallback Chain)**: หากโมเดลใดไม่พร้อมใช้งาน ระบบจะสลับไปยังโมเดลสำรองโดยอัตโนมัติทันที:
  1. `gemini-2.0-flash` (โมเดลหลัก รวดเร็วและแม่นยำสูง)
  2. `gemini-1.5-flash` (เสถียร รองรับทุกโปรเจกต์)
  3. `gemini-2.0-flash-lite` (ประหยัดโควตาและเบาแรง)
  4. `gemini-1.5-pro` (โมเดลสำรองระดับสูง)
- **ระบบอัปเกรดการตั้งค่าเดิมอัตโนมัติ (Preference Sanitization)**: อัปเดตการตั้งค่าในเครื่องที่เคยบันทึกค่าเดิมไว้ ให้สลับมาใช้ `gemini-2.0-flash` โดยที่ผู้ใช้ไม่ต้องล้างข้อมูลแอป
- **ปรับปรุงการแสดงผลทดสอบการเชื่อมต่อ**: แสดงชื่อโมเดลที่เชื่อมต่อสำเร็จจริง พร้อมระยะเวลาตอบสนอง (ms) อย่างชัดเจน
