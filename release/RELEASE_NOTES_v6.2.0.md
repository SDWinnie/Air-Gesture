## 🚀 มีอะไรใหม่ใน Air Gesture & Voice Companion v6.2.0 (Dual-Platform: Android + PC)

### 🎙️ 1. ระบบสั่งงานด้วยเสียงเต็มรูปแบบ 13 คำสั่ง (Complete Voice Navigation Suite)
- **13 คำสั่งเสียงธรรมชาติ (ไทย & อังกฤษ)**:
  1. ⬇️ *"เลื่อนลง"* / *"scroll down"* / *"ลง"* → เลื่อนหน้าจอลง
  2. ⬆️ *"เลื่อนขึ้น"* / *"scroll up"* / *"ขึ้น"* → เลื่อนหน้าจอขึ้น
  3. ❤️ *"กดใจ"* / *"ถูกใจ"* / *"like"* → ส่งหัวใจ (ดับเบิลคลิกกลางจอใน TikTok/Reels)
  4. 🔙 *"ย้อนกลับ"* / *"back"* → กดย้อนกลับ
  5. 🏠 *"หน้าแรก"* / *"home"* / *"หน้าหลัก"* → กลับหน้าโฮม
  6. 📱 *"สลับแอป"* / *"recents"* → เปิดหน้ารายการสลับแอป
  7. 🔊 *"เพิ่มเสียง"* / *"volume up"* → เร่งเสียง
  8. 🔉 *"ลดเสียง"* / *"volume down"* → ลดเสียง
  9. 🔇 *"ปิดเสียง"* / *"mute"* → ปิดเสียงสื่อทันที
  10. ⏯️ *"เล่น"* / *"หยุด"* / *"play"* / *"pause"* → สลับเล่น/หยุดเพลงหรือวิดีโอ
  11. 🎡 *"เมนูแอป"* / *"menu"* → เปิดวงกลมเลือกแอป 360° บนจอ
  12. 📸 *"แคปหน้าจอ"* / *"screenshot"* → ถ่ายภาพหน้าจอทันที
  13. 🔒 *"ล็อกมือ"* / *"lock hand"* → สลับหรือรีเซ็ตโหมดล็อกมือข้างเดียว
- **คู่มือคำสั่งเสียงในแอป**: เพิ่มปุ่ม *"📖 ดูรายการคำสั่งเสียงทั้งหมด (13 คำสั่ง)"* ในหน้าแอปเพื่อดูรายละเอียดและวิธีสั่งงาน
- **เสียงตอบกลับ TTS ภาษาไทยธรรมชาติ**: ยืนยันการสั่งงานด้วยเสียงพูดภาษาไทยทุกครั้ง

### 💻 2. เปิดตัวเวอร์ชันคอมพิวเตอร์ PC (Air Gesture & Voice for Windows)
- **รันบนคอมพิวเตอร์ Windows ได้ทันที**: เปิดไฟล์ `run_air_gesture_pc.bat` หรือ `python air_gesture_pc.py`
- **ระบบตรวจจับท่าทางมือ 3D หน้าจอคอม**:
  - แบมือปัดขึ้น/ลง → เลื่อนหน้าเว็บ, เอกสาร PDF, Word, Excel
  - ชี้กวักนิ้ว (Air Cursor) → ขยับเมาส์บนจอตามนิ้วมือแบบ 1-Euro Smooth Jitter Filter
  - จีบนิ้ว (Air Pinch) → คลิกซ้าย (Left Click)
  - ชู 2 นิ้ว (Victory) → คลิกขวา (Right Click)
  - กำมือ (Closed Fist) → สลับหน้าต่างโปรแกรม (Alt+Tab)
- **ระบบสบตา & กระพริบตาบน PC (Eye Contact Blink)**:
  - กระพริบตา 1 ครั้ง → เลื่อนลง
  - กระพริบตา 2 ครั้ง → เลื่อนขึ้น
  - กระพริบตา 3 ครั้ง → ดับเบิลคลิก
- **คำสั่งเสียงบน PC**: รับเสียงผ่านไมโครโฟนคอมพิวเตอร์ สั่งงานเลื่อนจอ เพิ่มลดเสียง หรือแคปหน้าจอ (Win+Shift+S)
- **AI Co-Processor**: เชื่อมต่อ Google Gemini 3.8 Flash และโมเดลล่าสุดฟรีในตัว
- **หน้าต่าง Cyberpunk Bento Glass**: แสดงสถานะกล้อง, FPS 60, ท่าทางมือสด, และสามารถย่อทำงานในพื้นหลัง (System Tray) ได้
